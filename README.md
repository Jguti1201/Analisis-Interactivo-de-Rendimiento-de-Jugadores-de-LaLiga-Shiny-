# ⚽ Análisis Interactivo de Rendimiento de Jugadores de LaLiga (Shiny)

Este proyecto implementa una **aplicación Shiny en R** para explorar y analizar de forma interactiva el rendimiento de jugadores de LaLiga. Permite filtrar por posición, equipo y jugador, visualizar métricas clave en gráficos interactivos y exportar los datos.

---

## 🧰 Tecnologías y librerías utilizadas

- **R**  
- **Shiny** → Desarrollo de la aplicación web interactiva  
- **dplyr, tidyr** → Manipulación de datos  
- **ggplot2, plotly** → Visualización interactiva  
- **DT** → Tablas dinámicas exportables  
- **readr** → Lectura de CSV  
- **RColorBrewer** → Paletas de colores
